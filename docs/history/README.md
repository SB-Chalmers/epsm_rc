# Historical calculation records

These files preserve experiments from RC 0.7.1, source revision
[`79c04461f1f2675d310eb8629d662db9ac8422c0`](https://github.com/SB-Chalmers/epsm_rc/tree/79c04461f1f2675d310eb8629d662db9ac8422c0).
The documents retain their original calculations and limitations, including paths
to scripts or datasets that are no longer part of the maintained package.

The archived BESTEST script is retained as source evidence. It depends on external
ASHRAE accompanying files and its old repository layout. Its printed comparisons
must not be treated as a current executable acceptance test or certification.
The maintained release tests use explicit fixtures and installed dependencies;
see [the benchmark guide](../../benchmarks/README.md).
